# Folio — CV Builder

Folio is a modern CV builder built with React and Vite.  
It helps users create professional resumes quickly with a clean interface, reusable templates, and real-time editing.

## Features

- Create and edit CV data in real time
- Multiple CV templates
- Responsive design for desktop and mobile
- Education and experience sections
- Skills and personal information
- Career-focused CV structure
- Clean and simple interface
- Easy to customize

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- ESLint
